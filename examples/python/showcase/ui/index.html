details name
Is there a browser inside?

No. A native engine parses the HTML, applies the CSS and draws the window itself.

Can I use JavaScript?

No. All behaviour lives in your backend, which receives events and changes the page.

Which platforms are supported?

Linux (Wayland) and Windows, with Python or PowerShell backends.
