A second HTML file

About this demo

The five showcase pages live in one document; the backend shows one section at a time. This page is different: it is a separate file, about.html, loaded into the same window.

  1. Loading a file replaces the whole document.
  2. The old document and its event handlers are retired.
  3. The backend registers handlers again for the new document.

The link below sends a link_activated event, and the backend loads index.html again, restoring the page, theme and counter it remembers.
